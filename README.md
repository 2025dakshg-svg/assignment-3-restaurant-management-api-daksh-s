# Hotel-management
# 🏨 Hotel Management API

A backend REST API for managing hotel/restaurant-related operations.  
The project is built with **Node.js, Express.js and MongoDB**, with authentication and API-based data management.

## 🚀 Live Deployment

🔗 **Render:** https://hotel-management-164a.onrender.com

## 📌 Project Overview

This project provides a backend API for a hotel/restaurant management application.

It follows a modular backend structure with separate:

- Controllers
- Models
- Routes
- Middleware
- Database configuration

The API is designed to handle application data and provide endpoints that can be consumed by a frontend application.

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **JWT (JSON Web Token)**
- **bcryptjs**
- **dotenv**

The project uses CommonJS modules and runs through `server.js`.  [oai_citation:2‡GitHub](https://raw.githubusercontent.com/2025dakshg-svg/Hotel-management/main/package.json)
